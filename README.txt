PINKSTORE PREMIUM — PETUNJUK SINGKAT

ISI
- index.html: halaman aplikasi
- style.css: desain
- products.js: katalog, ikon bergaya, kategori, dan harga
- app.js: pencarian, pilihan paket, tombol WhatsApp admin
- manifest.json + sw.js + folder icons: dukungan instalasi PWA dan cache

NOMOR ADMIN

HARGA
Harga awal di katalog adalah CONTOH, bukan harga resmi atau harga terverifikasi. Sebelum dipublikasikan, buka products.js lalu ubah nilai price sesuai harga/paket yang benar-benar kamu jual. Semua angka dalam Rupiah.

IKON
Aplikasi menampilkan ikon bergaya/emoji dan huruf sebagai placeholder, bukan logo resmi masing-masing merek. Jika ingin logo resmi, gunakan aset yang kamu punya izin untuk pakai.

CARA MENCOBA DI HP
1. Ekstrak ZIP ke folder di HP.
2. Untuk sekadar melihat tampilan, buka index.html melalui Acode.
3. Agar tombol instalasi PWA berfungsi, file harus diunggah ke hosting HTTPS (contoh GitHub Pages atau Netlify). Membuka index.html langsung dari file manager tidak cukup untuk instalasi PWA.
4. Setelah dipasang di HTTPS, buka URL situs di Chrome Android, lalu pilih Install App / menu ⋮ > Tambahkan ke layar utama.

CATATAN
Ini adalah aplikasi katalog dan pemesanan yang mengirim detail produk ke WhatsApp admin. Ini belum memproses pembayaran otomatis dan tidak membuat/menyediakan akun premium. Pastikan penjualan mematuhi aturan dan ketentuan resmi setiap layanan.
